# Сертификаты для исходящих запросов к MAX

Положите сюда корневой и промежуточный сертификаты Минцифры с PEM-содержимым
(`-----BEGIN CERTIFICATE-----`). Расширение может быть `.pem`, `.cer` или `.crt`.
Бинарный DER сначала преобразуйте по инструкции deployment. Файлы сертификатов
исключены из Git. При старте контейнер собирает `MAX_CA_BUNDLE` из системного
набора доверенных CA и всех PEM-файлов этой директории.

Подробная проверка описана в `docs/deployment.md`.
